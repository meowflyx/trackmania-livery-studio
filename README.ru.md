# Trackmania Livery Studio

**Экспериментальный ИИ-скилл/плагин для создания настоящих скинов Trackmania 2020 Stadium.**

Проект создан с помощью ИИ — ChatGPT Work / Codex: большая часть кода, инструкции и демонстрационная графика. Я сделал его публичным просто потому, что посчитал: он может пригодиться кому-то кроме меня. Он вырос из работы над моим собственным скином и исправления ошибок, а не из профессиональной команды разработки плагинов.

Это личный эксперимент, а не обещание «любая нейросеть с первого раза нарисует идеальный скин». Цель — настоящий импортируемый ZIP с DDS и редактируемыми исходниками, а не картинка машины вместо готового скина.

## Что внутри

- Исследование конкретной ливреи по команде, сезону и гонке.
- Генератор изображений для плоской графики/материалов, отдельные точные логотипы и надписи.
- Реальная геометрия и UV с масками кузова, спойлера и области номера.
- OpenRaster-слои, исходная графика и переносимый рецепт повторной сборки.
- DDS-экспорт и проверка всех сохранённых mipmap, структуры ZIP и форматов карт.
- Просмотрщик настоящих сжатых цветовых mipmap вместо красивого, но другого PNG-рендера.

Модель — **community-работа с CC BY 4.0**, не официальный шаблон Nadeo. Предыдущий Red Bull-скин, личные скриншоты и спонсорские логотипы в общий пакет не включены. Источники и лицензии: [THIRD_PARTY.md](THIRD_PARTY.md).

## Установка

Тестируемая сборка: **Windows x64**, Python 3.10+, Pillow и NumPy. Встроенный texconv — Windows-программа. На другой ОС нужен совместимый нативный экспортёр. Сам скилл не добавляет агенту генератор изображений, интернет или файловые инструменты: они должны присутствовать в выбранном окружении.

Через актуальный Codex CLI:

```text
codex plugin marketplace add meowflyx/trackmania-livery-studio
codex plugin add trackmania-livery-studio@trackmania-livery-studio
codex plugin list --json
```

Это установка из **GitHub community-marketplace**, не из официального каталога OpenAI. Если пункт не появился, обнови/перезапусти настольное приложение. В новом Work-чате введи `@` и выбери **Trackmania Livery Studio** в меню, затем дай запрос:

```text
@Trackmania Livery Studio Сделай импортируемый скин Trackmania 2020 по ливрее Ferrari на Гран-при США 2026 в Остине. Проверь реальные референсы, сохрани редактируемые исходники и осмотри готовые DDS со всех сторон.
```

Это пример вызова, не утверждение о существовании конкретной специальной ливреи. Если её подтвердить не удалось, скилл должен явно назвать результат адаптацией проверенного дизайна.

Без GitHub-загрузки можно распаковать marketplace ZIP из Releases и зарегистрировать полный путь к распакованной папке. Отдельный skill ZIP предназначен для других совместимых агентов: переносить нужно весь каталог с ресурсами. Совместимость манифеста Claude не означает, что полный запуск в Claude проверен.

## Python без вмешательства в существующее окружение

В клонированном репозитории:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r plugins/trackmania-livery-studio/skills/trackmania-livery-studio/scripts/requirements.txt
.\.venv\Scripts\python.exe plugins/trackmania-livery-studio/skills/trackmania-livery-studio/scripts/studio.py doctor
```

При необходимости укажи агенту этот интерпретатор. Установленный плагин может находиться в отдельном кеше. Автоматические скриншоты опциональны: для них нужны существующие Node.js, Playwright и браузер. Плагин сам не скачивает браузеры, не запускает установщики и не требует платного API-ключа.

## Проверки и ограничения

[VALIDATION.md](docs/VALIDATION.md) отделяет реальные тесты от ещё не проверенных вещей. Картинки в README — снимки внешнего просмотрщика. Они не доказывают игровой импорт, точное совпадение шейдера, работу дисплеев или анимацию крыла. Публичная сборка остаётся alpha; полный тест в игре нужно подтвердить отдельно.

Демонстрация [Ember](examples/ember) использует оригинальную ИИ-графику без сторонних команд/спонсоров. Она нужна для воспроизводимой проверки цепочки «генератор → UV → DDS → ZIP → просмотрщик». Исходный промпт и графический файл доступны.
